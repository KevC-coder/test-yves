# Arte republicano · Examen

Examen de práctica en español con 50 preguntas de selección única y cuatro opciones por pregunta, basado en el material de clase sobre arte republicano latinoamericano del siglo XIX.

## Probar el examen

Abre `index.html` en el navegador. Mantén los archivos del ZIP en la misma carpeta.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Descomprime el ZIP y sube todos los archivos a la raíz de la rama `main`. El archivo `index.html` debe quedar en esa raíz.
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**. Elige **main** y **/ (root)** y guarda.
5. Cuando GitHub termine el despliegue, abre la URL que aparece en **Settings → Pages**.

La web usa HTML, CSS y JavaScript. El progreso y el resultado se guardan en el navegador cuando el almacenamiento local está disponible. Las respuestas forman parte del JavaScript del sitio y se muestran en la interfaz al evaluar el examen.
