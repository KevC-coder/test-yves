# Arte republicano · Examen

Examen de práctica en español basado en el material de clase sobre arte republicano latinoamericano del siglo XIX. El banco contiene 100 preguntas de selección única con cuatro opciones por pregunta. Cada intento evalúa 25.

## Cómo se seleccionan las preguntas

El navegador mezcla el banco y reparte las preguntas en cuatro intentos de 25 sin repetir. Al completar el ciclo vuelve a mezclar el banco y comienza por un grupo distinto al del intento anterior. La selección y las respuestas se conservan al recargar mientras el navegador permita usar el almacenamiento local.

## Probar el examen

Abre `index.html` en el navegador. Mantén los archivos del ZIP en la misma carpeta.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub.
2. Descomprime el ZIP y sube todos los archivos a la raíz de la rama `main`. El archivo `index.html` debe quedar en esa raíz.
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**. Elige **main** y **/ (root)** y guarda.
5. Cuando GitHub termine el despliegue, abre la URL que aparece en **Settings → Pages**.

La web usa HTML, CSS y JavaScript. Al evaluar, el resultado muestra la puntuación sobre 25 y la revisión de las preguntas de ese intento. Las respuestas forman parte del JavaScript del sitio y se muestran en la interfaz al evaluar el examen.
